## Проекты

### QA — Тестирование и артефакты
Здесь собраны практические работы по тестированию:

- **Тест-кейсы и чек-листы** — покрытие функционала веб-приложения
- **Баг-репорты** — примеры качественных отчётов о дефектах с шагами воспроизведения
- **Тест-план** — планирование тестирования для учебного проекта
- **API-тестирование** — коллекция Postman для REST API (GET, POST, проверка статусов)
- **Web-тестирование** — работа с DevTools, анализ ответов сервера, UI/UX проверки

---

### SQL — PostgreSQL и базы данных
Проекты по работе с базами данных:

- **Database Index** — оптимизация запросов через индексы (B-tree, Hash, GiST), анализ производительности
- **Salesman Problem** — моделирование графов, поиск оптимальных маршрутов через SQL
- **Snapshots** — работа с временными диапазонами, материализованными представлениями, расчёт скидок
- **Isolation Levels** — транзакции, уровни изоляции, воспроизведение аномалий (Lost Update, Dirty Read)
- **Functions and Procs** — хранимые процедуры, триггеры, аудит изменений данных
