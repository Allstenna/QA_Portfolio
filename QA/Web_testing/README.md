## Задание 2. Протоколы HTTP и HTTPS 

1. Изучи схему работы HTTPS-протокола. Опиши каждый шаг установления защищенного соединения между браузером и сервером.
Для каждого шага укажи: 

    - Какую цель преследует этот этап; 

    - Какой риск он устраняет.

    Формат: пронумерованный список с разделением на шаги.

2. Открой любой HTTPS-сайт, с помощью инструментов разработчика в браузере найди информацию о сертификате. 

    - Какая версия TLS используется?

    - Кто выпустил сертификат? Действителен ли он?

    Сделай скриншот сертификата, укажи название анализируемого сайта и, основываясь на данных, напиши, какие этапы прошли успешно, а какие скрыты в браузере. 

3. Изучи основные основные группы кодов состояния HTTP (1xx, 2xx, 3xx, 4xx, 5xx) и создай практическую шпаргалку, которую можно использовать при тестировании. Для каждой группы создай таблицу с колонками:

    |---|---|---|---|---|
    |   |   |   |   |   |

4. Выполненное задание (список, скриншоты, таблицы) оформи в документе `task_2.md`.

## Задание 3. Cookies

1. Перейди на любой сайт, который использует Cookies (обычно в 100% случаев это интернет-магазины).
2. Открой Chrome DevTools и во вкладке «Application» найди сведения о Cookies. 
3. Исследуй и оформи ответы на следующие вопросы в документе `task_3.md`.
4. Укажи адрес сайта. Выбери 5 разных cookies из списка, опиши их по следующим критериям: имя, тип, предполагаемое назначение (для чего он используется)
5. Изучи флаги (Secure, HttpOnly, SameSite) для всех cookies, которые, на твой взгляд, содержат критичные данные (например, идентификатор сессии). 
Опиши, считаешь ли ты эту настройку безопасной и почему.
6. Добавь любой товар в корзину покупок. Вернись во вкладку Application и обнови список cookies. Найди cookie, который, по твоему мнению, отвечает за корзину? Опиши, как изменилось его значение после твоего действия? Опиши этот cookie (имя, флаги).
7. Найди cookie, который, скорее всего, отвечает за сессию или аутентификацию. Вручную удали его прямо в DevTools. После этого обнови страницу в браузере. Что произошло? Опиши изменения в поведении сайта. 
8. Приложи скриншот DevTools, где видно удаление cookie (с его названием).
