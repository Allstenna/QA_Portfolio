# Тестирование UI веб-сайта
## Баг-репорт
### Блок «Кампусы» отображается пустым белым прямоугольником вместо контента

*Критичность*: High

*Серьёзность*: Major

*Статус*: Открыт

*Автор*: Veliamol

*Шаги воспроизведения*:

1.  Открыть `21school.html` в папке `21school_web site`
2.  Пролистать до конца блока "Методология"

*Окружение*: Firefox 149.0 (64-разрядный) (Desktop)

*Ожидаемый результат*: Отображается блок "Кампусы" согласно макету

*Фактический результат*: Отображается белый блок с `max-width: 1440px;`. Внутри находятся три `<div>` с свойствами, а также элемент `<canvas>`.

*Гипотеза*: тег `<canvas>` используется для создания визуальных элементов через JS, следовательно, проблема может заключаться в:
- Неправильное подключение JavaScript к HTML-файлу (не указан путь / отсутствует полностью); 
- Блокируется использование JS-скриптов на сайте; 
- Подключаемый файл JS пуст / неправильно обрабатывает функции внутри него.


## Баг-репорт
### Наличие лишней кнопки "Подробнее о методике" в разделе "Методология"

*Критичность*: Low

*Серьёзность*: Minor

*Статус*: Открыт

*Автор*: Veliamol

*Шаги воспроизведения*:

1.  Открыть `21school.html` в папке `21school_web site`
2.  Пролистать до блока "Методология"
3. Увидеть кнопку "Подробнее о методике" и сравнить с макетом [ссылка](https://www.figma.com/design/eTKqLIoG72PDLMuLUM4g7n/%D0%A1%D0%B1%D0%B5%D1%8021?node-id=0-1&p=f&t=RjUL4JjViM28JAQn-0)

*Окружение*: Firefox 149.0 (64-разрядный) (Desktop)

*Ожидаемый результат*: В блоке "Методология" находится название блока ("Методология"), описание, перечисление навыков (в виде списка), изображение. Кнопка "Подробнее о методике" должна отсутствовать.

*Фактический результат*: Под списком приобретаемых навыков отображается кнопка "Подробнее о методике".

*Гипотеза*: Разработчик сверстал дополнительную кнопку, не сверившись с утвержденным макетом сайта.


## Баг-репорт
### Наличие не предусмотренных макетом контента с видео в секции "Участники и выпускники о "Школе 21""

*Критичность*: Medium

*Серьёзность*: Minor

*Статус*: Открыт

*Автор*: Veliamol

*Шаги воспроизведения*:

1.  Открыть `21school.html` в папке `21school_web site`
2.  Пролистать до блока "Участники и выпускники о "Школе 21""
3. Увидеть наличие видео с описанием внутри слайдера и сравнить с макетом [ссылка](https://www.figma.com/design/eTKqLIoG72PDLMuLUM4g7n/%D0%A1%D0%B1%D0%B5%D1%8021?node-id=0-1&p=f&t=RjUL4JjViM28JAQn-0)

*Окружение*: Firefox 149.0 (64-разрядный) (Desktop)

*Ожидаемый результат*: В блоке "Участники и выпускники о "Школе 21"" должны отображаться только стрелки слайдера.

*Фактический результат*: Под стрелками слайдера находится слайдер с содержимым в виде иконы воспроизводства видео, имя участника, его статус и текущая должность.

*Гипотеза*: Разработчик сверстал слайдер, не сверившись с утвержденным макетом сайта.
