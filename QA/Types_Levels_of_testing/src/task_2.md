# Black-box 
|Требование|Статус| 
|-|-| 
|**SC21-01 Поле ввода названия магазина**||
|*Поле принимает латинские буквы (заглавные/строчные)*||
|*Поле принимает кириллические буквы (заглавные/строчные)*||
|*Поле принимает цифры (арабские/римские)*||
|*Поле принимает пробелы, тире и дефисы*||
|*Поле принимает спецсимволы*||
|*При открытии поля отображается плейсхолдер*||
|*Плейсхолдер исчезает при фокусе на поле (до ввода символов)*||
|*Плейсхолдер исчезает при вводе первого символа*||
|*При вводе 0 символов кнопка «Поиск» неактивна*||
|*При вводе 1 символа кнопка «Поиск» неактивна (проверка минимальной границы)*||
|*При вводе 2+ символов кнопка «Поиск» активна*||
|*После поиска запрос сохраняется в истории*||
|*При повторном открытии приложения история поиска отображается*||
|**SC21-02 Поле выбора типа магазина**||
|*Поле реализовано как выпадающее меню (не чекбоксы/радиокнопки)*||
|*В списке присутствует опция «Продуктовые магазины»*||
|*В списке присутствует опция «Магазины стройматериалов»*||
|*В списке присутствует опция «Аптеки»*||
|*При открытии поля отображается плейсхолдер «Выберите тип магазина»*||
|*После выбора значения плейсхолдер заменяется выбранным типом*||
|*Выбранное значение корректно отображается в закрытом состоянии меню*||
|**SC21-03 Кнопка «Поиск»**||
|*Кнопка неактивна при пустом поле названия + пустом типе магазина*||
|*Кнопка активна при заполнении поля названия (2+ символа) + пустом типе*||
|*Кнопка активна при пустом поле названия + выбранном типе магазина*||
|*Кнопка активна при заполнении обоих полей*||
|*После поиска результаты отображаются на карте в виде флажков*||
|*Карта реагирует на свайп для перемещения (скроллинг)*||
|*Карта реагирует на «зуммирование» для масштабирования*||
|*При отсутствии результатов отображается сообщение об ошибке*||
|**SC21-04 Кнопка «Построить маршрут»**||
|*Кнопка неактивна при отсутствии результатов поиска*||
|*Кнопка активна после выбора флага магазина на карте*||
|*Кнопка активна при выбранном типе магазина (без поиска по названию)*||
|*Надпись на кнопке: «Построить маршрут»*||
|*Цвет фона кнопки: #FFFFFF (белый)*||
|*При нажатии фон кнопки меняется на #586d73 (серый)*||
|*При нажатии надпись меняется на «Отменить маршрут»*||
|*Повторное нажатие возвращает исходный вид кнопки (#FFFFFF + «Построить маршрут»)*||
|**SC21-05 Область карты**||
|*Высота области карты составляет ровно 50% высоты экрана (визуальная проверка)*||
|*Маршрут строится только после выполнения условий из SC21-04*||
|*При построенном маршруте отображается линия пути на карте*||
|*Отмена маршрута возможна только через кнопку «Отменить маршрут»*||
|*Свайп/зум карты не приводит к отмене маршрута*||
|**SC21-06 Общие требования**||
|*После закрытия и повторного открытия приложения отображается незавершённый маршрут (если был построен)*||
|*При заряде аккумулятора < 20% отключается режим точной геопозиции*||
|*При отключённой точной геопозиции отображается уведомление пользователю*||
|*При заряде аккумулятора > 20% точная геопозиция автоматически включается*||
